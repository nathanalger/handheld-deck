# Handheld Deck
This is a in-progress project where I intend to combine a RP2040 Microcontroller (for peripheral control and communication) with a RK3566 SoC for system processing, networking, and display output. 

# Prototyping
For prototyping, I am using these components together:
1. [OrangePI](https://a.co/d/0dy2n22j)
2. [PI Pico 2](https://a.co/d/03YAkhTz)
3. [FT232RL](https://a.co/d/02JEHYMy) for UART debugging
